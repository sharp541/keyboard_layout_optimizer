# T05: 可変長入力列コスト評価を追加する

## 目的

2 打短縮を正しく評価できるように、固定 tri-gram 以外の入力列コスト API を追加する。

## 作業内容

- `PhysicalLayout` に 2 打コスト API を追加するか別評価器を実装する
- 可変長入力列を受け取る評価関数を作る
- 2 打と 3 打をどう合成するかを決める
- 既存 tri-gram コストとの整合を確認する

## 成果物

- 可変長入力列コスト評価 API
- 単体テスト

## 変更候補ファイル

- `src/keyboard_layout/physical_layout.rs`
- `src/evaluator/sequence_cost.rs`

## 完了条件

- 2 打短縮が 3 打入力と区別して評価される
- 数件の手計算ケースで妥当なコスト差になる
