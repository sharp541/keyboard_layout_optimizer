# T08: 統合評価器を追加する

## 目的

英語評価と日本語評価を別々に計算し、重み付きで合成できる評価器を追加する。

## 作業内容

- `english_score` と `japanese_score` を受け取る合成 API を作る
- `ja_weight`, `en_weight` を受け取って正規化する
- 片側だけ有効なケースも扱えるようにする

## 成果物

- 統合評価器
- 合成ルールのテスト

## 変更候補ファイル

- `src/evaluator/combined.rs`
- `src/evaluator/mod.rs`

## 完了条件

- 将来の重み変更で他実装に波及しない
