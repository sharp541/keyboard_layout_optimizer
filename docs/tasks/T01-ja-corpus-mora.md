# T01: 日本語コーパスをかな/モーラ列として保持する

## 目的

`python/dataset.py` の日本語出力を、現行の訓令式ローマ字列ではなく、かな列またはモーラ列として保存できるようにする。

## 背景

現状の `data/ja.txt` は `pykakasi` による `kunrei` ローマ字化済みであり、AZIK 系の出力列評価には不向き。

## 作業内容

- `python/dataset.py` の日本語加工処理を見直す
- 少なくとも `data/ja_kana.txt` または同等の出力を追加する
- 可能ならモーラ分割済み形式の出力も用意する
- 句読点、空白、文末記号の正規化方針を決める

## 成果物

- 日本語のかなまたはモーラ列データ
- 前処理仕様に対応するコード

## 変更候補ファイル

- `python/dataset.py`

## 完了条件

- 日本語データがローマ字ではなく出力列ベースで保存される
- 簡単なサンプル入力に対して期待形式で出力される

## メモ

- 英語側の `data/en.txt` はこのタスクでは変更しない
