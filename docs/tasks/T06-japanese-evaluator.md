# T06: 日本語評価器を追加する

## 目的

日本語コーパス、役割付きレイアウト、AZIK 系デコーダ、可変長コスト評価をつないだ日本語専用評価器を実装する。

## 作業内容

- 日本語出力列頻度を入力に取る
- 各出力列を現在レイアウトで実現する入力列候補へ変換する
- 最良候補コストで日本語スコアを集計する
- 将来の重み付けに使いやすい API へまとめる

## 成果物

- 日本語評価器
- 単体テストまたは評価スモークテスト

## 変更候補ファイル

- `src/evaluator/japanese.rs`
- `src/evaluator/mod.rs`

## 完了条件

- 日本語専用スコアが単独で計算できる
- 英語評価器へ依存しない
