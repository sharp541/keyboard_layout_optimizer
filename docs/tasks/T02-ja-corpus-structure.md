# T02: 日本語評価用コーパス構造を追加する

## 目的

日本語のかな/モーラ列頻度を保持し、評価器から参照できる構造を Rust 側へ追加する。

## 作業内容

- `src/n_gram.rs` とは別の日本語コーパス表現を設計する
- モーラ列または出力列ごとの頻度集計 API を作る
- 必要なら新規モジュール `src/corpus/ja_mora.rs` を追加する
- テスト用の小さい入力で頻度が取得できることを確認する

## 成果物

- 日本語コーパス読み込み構造
- 頻度取得 API
- 単体テスト

## 変更候補ファイル

- `src/lib.rs`
- `src/corpus/mod.rs`
- `src/corpus/ja_mora.rs`

## 完了条件

- 日本語出力列頻度が Rust 側で読み出せる
- 既存の英語 `NGramDB` と分離されている
