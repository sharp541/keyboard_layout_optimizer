# T09: GA を役割付き配置へ拡張する

## 目的

GA の個体表現を、文字順列中心から役割付き配置を扱える形へ拡張する。

## 作業内容

- 個体が役割付きレイアウトを保持できるようにする
- mutation と crossover が役割配置でも破綻しないようにする
- 統合評価器を通じてスコア計算する
- 初期個体生成方針を決める

## 成果物

- 役割付き GA
- スモークテスト

## 変更候補ファイル

- `src/algorithms/genetic.rs`
- `src/keyboard_layout/logical_layout.rs`

## 完了条件

- 役割付き配置で最適化ループが回る
- スコア計算が英語/日本語統合評価器へ接続されている
