# T04: AZIK 系デコーダを実装する

## 目的

キー役割列から、日本語の出力モーラ列を生成する一般化デコーダを実装する。

## 対象範囲

- 基本子音 + 母音
- `ann / inn / unn / enn / onn`
- `ai / uu / ei / ou`

## 作業内容

- デコーダの入出力型を設計する
- 役割列から出力モーラ列への変換を実装する
- 妥当でない組み合わせを弾く
- 簡単なケースの単体テストを追加する

## 成果物

- AZIK 系デコーダ
- 単体テスト

## 変更候補ファイル

- `src/input_method/mod.rs`
- `src/input_method/mora.rs`
- `src/input_method/decoder.rs`

## 完了条件

- 役割列から `かん`, `こう`, `せい` 相当の出力が導ける
- 初期対象外の規則を無理に通さない
