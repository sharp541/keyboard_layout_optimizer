# T07: 英語評価器を分離する

## 目的

現行の英語評価ロジックを独立した評価器として切り出し、日本語評価と分離する。

## 作業内容

- `LogicalLayout::evaluate_ids` を呼ぶ現行経路を整理する
- 英語評価に必要な tri-gram 前処理を専用モジュールへ寄せる
- 既存のスコア結果が大きく変わらないことを確認する

## 成果物

- 英語評価器
- 回帰確認テスト

## 変更候補ファイル

- `src/algorithms/genetic.rs`
- `src/evaluator/english.rs`
- `src/evaluator/mod.rs`

## 完了条件

- 英語スコアを単独で計算できる
- 現行コードの評価経路と分離されている
